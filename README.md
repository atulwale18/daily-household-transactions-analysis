
# Daily Household Transactions Analysis

This project analyzes daily household financial transactions to understand
spending patterns, income vs expense behavior, and monthly trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis
- Data cleaning and preprocessing
- Income vs Expense analysis
- Category-wise spending
- Payment mode analysis
- Monthly expense trends

## Output
- Jupyter Notebook with code and visualizations
- PDF report with graphs and insights
